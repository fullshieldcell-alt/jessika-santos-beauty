# Jéssika Santos Beauty — site

Site do estúdio de sobrancelhas e estética regenerativa da Jéssika Santos (Tambaú, SP).
Feito pela Nexux Marketing Digital.

- `index.html` — página única (HTML + CSS + JS no mesmo arquivo)
- `img/` — fotos do site (para trocar uma foto, substitua o arquivo mantendo o mesmo nome)

Para visualizar: abra a pasta no VS Code e use a extensão Live Server.
